# Valsugana Offline

Prototipo di mappa 3D offline per escursioni in Valsugana e Lagorai, come PWA installabile.

**Apri l'app: https://alexroat.github.io/valsugana/** · anteprima da computer: https://alexroat.github.io/valsugana/preview.html

Questo repository contiene solo l'app compilata e il pacchetto dati (contenuti v2026110501).
